# Кнопка "Перенести в реестр заказчика" в пакетном Excel-отчёте

Разовая ручная настройка (2-3 минуты) — один раз в НАСТОЯЩЕМ Microsoft Excel
(не в WPS Office и не в другом аналоге — важно, чтобы файл сохранил
работоспособный VBA-проект и кнопку). После этого приложение само переиспользует
готовый шаблон для каждого нового пакетного отчёта — повторять эти шаги не нужно.

## Шаги

1. Сделайте в приложении любую пакетную проверку — появится файл вида
   `Отчет по пакету актов ...xlsx` (можно взять любой уже готовый).
2. Откройте его в настоящем Excel. Если по умолчанию `.xlsx` открывается в WPS —
   запустите Excel напрямую (обычно `C:\Program Files\Microsoft Office\root\Office16\EXCEL.EXE`
   или через Пуск → Excel) и откройте файл через "Файл → Открыть" внутри него.
3. Перейдите на лист **"Реестр"**.
4. Откройте редактор VBA: `Alt+F11`.
5. В дереве проекта (слева) правой кнопкой по названию книги → `Insert → Module`.
6. Откройте файл `AppendToMasterRegistry.bas` (лежит рядом с этим README) и
   скопируйте его содержимое целиком в открывшийся пустой модуль.
7. Закройте редактор VBA (`Alt+Q` или крестик).
8. На листе "Реестр": вкладка `Разработчик` (Developer) → `Вставить` (Insert) →
   в группе "Элементы управления формы" (Form Controls) выберите **Кнопка** (Button).
   Если вкладки "Разработчик" нет — включите её: `Файл → Параметры → Настройка ленты →
   поставить галочку "Разработчик"`.
9. Нарисуйте кнопку в любом свободном месте листа (справа от таблицы, чтобы не
   перекрывать данные — например, в районе колонки P).
10. В появившемся диалоге "Назначить макрос" выберите `AppendToMasterRegistry` → ОК.
11. Кликните по кнопке ещё раз правой кнопкой → `Изменить текст` → впишите, например,
    "Перенести в реестр заказчика".
12. Сохраните файл как **`batch_report_template.xlsm`** (тип файла — "Книга Excel
    с поддержкой макросов") и положите его сюда:
    `data/templates/batch_report_template.xlsm` (в корне проекта).

Готово. С этого момента `src/utils/batch_report.py` берёт этот файл как основу
для каждого нового пакетного отчёта (копирует его и заполняет данными через
openpyxl, сохраняя макрос и кнопку) — при условии, что шаблон лежит по этому
пути. Если файла там нет — отчёт по-прежнему строится как обычный `.xlsx` без
кнопки (ничего не ломается, просто без этой возможности).

## Что делает кнопка

При нажатии открывает диалог выбора файла → просит выбрать ваш мастер-реестр
(например, "Проверка акт-нарядов 2026 г.xlsx") → дописывает в его первый лист
все строки из текущего листа "Реестр" (кроме шапки), правильно продолжая
нумерацию "№ п/п" (и его сброс при смене "Дата предоставления") с того места,
на котором остановился мастер-реестр → сохраняет мастер-реестр.

## Важно

- На корпоративных ПК макросы нередко блокируются политикой безопасности —
  при открытии файла может появиться жёлтая полоса "Включить содержимое"
  (Enable Content), без нажатия которой кнопка работать не будет.
- Разовую настройку (шаги выше) нужно делать именно в настоящем Excel — WPS
  на этой машине блокирует программное создание VBA-модулей, поэтому автоматически
  собрать шаблон не вышло.
