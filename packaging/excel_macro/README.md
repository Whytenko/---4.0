# Кнопка "Перенести в реестр заказчика"

Отдельный небольшой файл-"лаунчер" (`batch_report_template.xlsm`) с одной
кнопкой. Он НЕ встраивается в приложение и не пересоздаётся программой —
это просто ваш личный инструмент, который вы держите где угодно (на
Рабочем столе, например) и открываете, когда нужно перенести данные из
свежего отчёта в мастер-реестр.

Почему не встроено в сам отчёт "Отчет по пакету актов...xlsx": библиотека,
которой приложение собирает Excel-файлы (openpyxl), не умеет сохранять
кнопки/фигуры при повторной записи файла — при любой попытке дозаписать
данные в уже готовый файл с кнопкой кнопка бесследно исчезает. Поэтому
кнопка живёт в отдельном, всегда одном и том же файле, который сама
программа больше не трогает.

## Разовая настройка (уже сделана, если вы прошли инструкцию ранее)

1. `Alt+F11` в файле → правой кнопкой по имени книги → `Insert → Module`.
2. Вставить код из `AppendToMasterRegistry.bas` (лежит рядом с этим README).
3. Закрыть редактор VBA (`Alt+Q`).
4. Вкладка `Разработчик` → `Вставить` → Кнопка (элемент управления формы) →
   нарисовать на листе → назначить макрос `AppendToMasterRegistry`.
5. Сохранить как `.xlsm` — можно под любым именем, в любом удобном месте
   (например, `Рабочий стол\Перенос в реестр.xlsm`).

## Если код макроса поменялся (как сейчас)

Код в `AppendToMasterRegistry.bas` изменился — теперь макрос запрашивает
ДВА файла вместо одного (сначала свежий отчёт, потом мастер-реестр), а не
берёт данные из самого себя. Нужно заменить код в уже созданном файле:

1. Откройте ваш существующий `batch_report_template.xlsm` (или как вы его
   назвали) в настоящем Excel.
2. `Alt+F11` → в дереве слева раскройте `Modules` → откройте `Module1`.
3. Выделите весь текст в модуле (`Ctrl+A`) и удалите.
4. Вставьте новый код из `AppendToMasterRegistry.bas`.
5. `Alt+Q`, сохранить (`Ctrl+S`, оставить формат `.xlsm`).

Кнопку и её привязку менять не нужно — она вызывает макрос по тому же
имени (`AppendToMasterRegistry`).

## Как пользоваться

1. Откройте ваш файл-лаунчер (`batch_report_template.xlsm` или как вы его
   назвали) в Excel.
2. Нажмите кнопку.
3. Шаг 1/2: выберите файл со свежим отчётом ("Отчет по пакету актов
   ....xlsx") — из него возьмутся строки с листа "Реестр".
4. Шаг 2/2: выберите файл вашего мастер-реестра (например, "Проверка
   акт-нарядов 2026 г.xlsx") — в него допишутся строки, с правильным
   продолжением нумерации "№ п/п" (и её сбросом при смене даты).
5. Мастер-реестр сохранится автоматически, появится сообщение "Готово:
   добавлено строк N".

## Важно

- На корпоративных ПК макросы нередко блокируются политикой безопасности —
  при открытии файла может понадобиться нажать жёлтую полосу "Включить
  содержимое" (Enable Content).
- Лаунчер-файл можно использовать сколько угодно раз для разных отчётов —
  один раз настроили, и он не меняется.
