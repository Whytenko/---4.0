# Кнопка "Перенести в реестр заказчика" — прямо в "Проверка акт-нарядов ....xlsx"

Кнопка встраивается прямо в ваш мастер-реестр (например, "Проверка
акт-нарядов 2026 г.xlsx"). Это безопасно навсегда: приложение никогда
программно не пересобирает и не перезаписывает этот файл — он полностью
ваш, кнопка никуда не денется.

## Разовая настройка (~3 минуты)

1. Откройте "Проверка акт-нарядов 2026 г.xlsx" в настоящем Excel (не WPS —
   если по умолчанию файл открывается в WPS, запустите Excel напрямую и
   откройте файл через "Файл → Открыть" уже внутри него).
2. `Alt+F11` — откроется редактор VBA.
3. В дереве слева (Project Explorer) правой кнопкой по названию книги →
   `Insert → Module`.
4. Откройте файл `AppendToMasterRegistry.bas` (лежит рядом с этим README),
   скопируйте весь код и вставьте в пустой модуль.
5. Закройте редактор VBA (`Alt+Q`).
6. Если нет вкладки "Разработчик" — включите: `Файл → Параметры → Настройка
   ленты` → галочка "Разработчик".
7. На листе с данными (обычно "Лист1"): вкладка `Разработчик` → `Вставить`
   → в разделе "Элементы управления формы" выберите **Кнопку** → нарисуйте
   её **в строке 1**, в любой свободной колонке справа от данных (например,
   в районе колонки P).
8. В окне "Назначить макрос" выберите `AppendToMasterRegistry` → ОК.
9. Правой кнопкой по кнопке → "Изменить текст" → напишите, например:
   "Перенести данные из отчёта".
10. Сохраните файл (`Ctrl+S`, формат оставить обычный `.xlsx` — макрос
    Excel всё равно предложит пересохранить как `.xlsm`, соглашайтесь).

## Чтобы кнопка не пропадала из виду при прокрутке вниз

Раз кнопка нарисована в строке 1 — закрепите эту строку через `Вид →
Закрепить области → Закрепить верхнюю строку`. Тогда при прокрутке вниз
по тысячам строк реестра шапка таблицы и кнопка всегда останутся на
экране.

## Как пользоваться

1. Нажмите кнопку прямо в реестре.
2. В открывшемся диалоге выберите файл со свежим отчётом ("Отчет по
   пакету актов ....xlsx") — диалог сразу откроется в рабочей папке
   приложения (`%LOCALAPPDATA%\AktNaryadVerifier\output`), куда оно
   реально сохраняет отчёты (не только открывает) — искать файл по
   всему компьютеру не нужно.
3. Переносятся ОБА листа источника:
   - "Реестр" → допишется в конец первого листа этой книги, с правильным
     продолжением нумерации "№ п/п" (и сбросом второго "№ п/п" при смене
     "Дата предоставления");
   - "Сводка" (все проверки по каждому акту с цветовой подсветкой) →
     допишется в лист "Сводка" этой же книги — при первом переносе он
     создастся автоматически, дальше просто пополняется, подсветка
     сохраняется.
4. Книга сохранится автоматически, появится сообщение "Готово" с
   количеством добавленных строк по каждому листу.

## Если код макроса уже был вставлен раньше

Код обновился (диалог теперь сразу открывается в папке отчётов, плюс
добавился перенос листа "Сводка") — замените код в уже созданном модуле:
1. Откройте ваш "Проверка акт-нарядов ....xlsx" → `Alt+F11`.
2. Слева `Modules` → `Module1` → выделите весь код (`Ctrl+A`) → удалите.
3. Вставьте новый код из `AppendToMasterRegistry.bas` → `Alt+Q` → сохранить.

## Важно

- На корпоративных ПК макросы нередко блокируются политикой безопасности —
  при открытии файла может понадобиться нажать жёлтую полосу "Включить
  содержимое" (Enable Content).
- Разовую настройку (шаги выше) нужно делать именно в настоящем Excel —
  на части машин (в т.ч. у разработчика) роль "Excel" в системе перехватывает
  WPS Office и блокирует программное создание VBA-модулей, поэтому
  автоматически собрать кнопку не вышло — только вручную, один раз.
